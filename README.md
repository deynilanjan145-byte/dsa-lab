# DSA Lab 🧠

A collection of Data Structures and Algorithms implementations in **C**, written and maintained as a personal practice lab covering arrays, linked lists, stacks, queues, trees, heaps, strings, and recursion.

## 📖 About

This repository is a growing collection of classic Data Structure and Algorithm implementations, built to strengthen core programming and problem-solving fundamentals. Each topic lives in its own folder with self-contained, compilable C source files.

## 🗂️ Topics Covered

| Topic | Description |
|---|---|
| **Searching** | Binary search on arrays, square-root based searching |
| **Trees** | Binary Search Tree (BST) construction and search |
| **Heaps** | Max-heap and min-heap implementations |
| **Queue** | Standard queue operations (enqueue/dequeue) |
| **Stack** | Stack operations, array reversal, and a stack-based text editor |
| **Strings** | Core string manipulation algorithms |
| **Linked List** | Insertion, deletion, and search on singly linked lists |
| **Recursion** | Factorial, Fibonacci, and summation using recursion |

## 🚀 Getting Started

### Prerequisites

- A C compiler such as [GCC](https://gcc.gnu.org/) installed on your system

### Compiling and Running

Clone the repository:

```bash
git clone https://github.com/deynilanjan145-byte/dsa-lab.git
cd dsa-lab
```

Compile any `.c` file using GCC:

```bash
gcc "Stack/stack.c" -o stack
./stack
```

Replace the path with the file you want to run. Each folder contains standalone programs that can be compiled and executed independently.
